# 氓

---
<style>pre {white-space: pre-wrap !important; word-break: break-all;}</style>氓
	《詩說・鄘・氓》：淫婦為人所棄，鄘人述其事以刺之，首二章皆賦也，三、四五皆興也，五章賦也，六章賦中有比也。
	感覺不是「淫婦為人所棄」，而是女人嫁錯郎的遺憾。
	
	衛國大致在今河南安陽、鶴壁、濮陽一帶，由封康叔建國定都於朝歌（今河南淇縣）。

---

>氓之蚩蚩，抱布貿絲。匪來貿絲，來即我謀。送子涉淇，至于頓丘。匪我愆期，子無良媒。將子無怒，秋以為期。

>乘彼垝垣，以望復關。不見復關，泣涕漣漣。既見復關，載笑載言。爾卜爾筮，體無咎言。以爾車來，以我賄遷。

>桑之未落，其葉沃若。于嗟鳩兮，無食桑葚。于嗟女兮，無與士耽。士之耽兮，猶可說也。女之耽兮，不可說也。

>桑之落矣，其黃而隕。自我徂爾，三歲食貧。淇水湯湯，漸車帷裳。女也不爽，士貳其行。士也罔極，二三其德。

>三歲為婦，靡室勞矣。夙興夜寐，靡有朝矣。言既遂矣，至于暴矣。兄弟不知，咥其笑矣。靜言思之，躬自悼矣。

>及爾偕老，老使我怨。淇則有岸，隰則有泮。總角之宴，言笑晏晏。信誓旦旦，不思其反。反是不思，亦已焉哉。

	氓之蚩蚩，抱布貿絲：氓，méng ㄇㄥˊ，《說文》「氓，民也。」本義爲外來的百姓，這裏指自彼來此之民，男子之代稱。蚩蚩，chī ㄔˉ：憨厚、老實的樣子。一說無知貌，一說戲笑貌。貿：交易。抱布貿絲是以物易物。
	匪來貿絲，來即我謀：是說那人並非真來買絲，是找我商量事情來了，所商量的事情就是結婚。匪，讀爲「非」。即，就。謀，méi ㄇㄟˊ，商量。
	淇：水名。（今河南淇河）
	頓丘：地名。（今河南清豐）丘：古讀如「欺」。
	愆，qiān  ㄑㄧㄢˉ：過，誤。這句是說並非我要拖延約定的婚期而不肯嫁，是因爲你沒有找好媒人。
	將，qiāng  ㄑㄧㄤˉ：願，請。
	垝，guǐ  ㄍㄨㄟˇ：倒塌；倒塌的。垣，yuán  ㄩㄢˊ：牆。
	不見復關，泣涕漣漣：她初時不見彼氓回到關門來，以爲他負約不來了，因而傷心淚下。復關：有多種解釋，其中之一指衛國的一個地方。復：返。關：在往來要道所設的關卡。女望男到期來會。他來時一定要經過關門。一說「復」是關名。涕：淚。漣漣：涕淚下流貌。
	載笑載言：（因爲高興而）又說又笑。載：語氣助詞。
	爾卜爾筮，體無咎言。以爾車來，以我賄遷：是說你從卜筮看一看吉凶吧，只要卜筮的結果好，你就打發車子來迎娶，並將嫁妝搬去。卜筮，燒灼龜甲的裂紋以判吉凶叫做「卜」，用蓍（shī  ㄕˉ）草占卦叫做「筮」。體，指龜兆和卦兆，即卜筮的結果。無咎言，就是無凶卦。賄，財物，指妝奩（lián  ㄌㄧㄢˊ）。
	沃若：猶「沃然」，像水浸潤過一樣有光澤。以上二句以桑的茂盛時期比自己戀愛滿足，生活美好的時期。
	于嗟鳩兮：于通「籲」（xū）本義爲表示驚怪、不然、感慨等，此處與嗟皆表感慨。鳩，斑鳩，傳說斑鳩吃桑葚過多會醉。
	耽：沉溺，貪樂太甚。
	說：通「脫」，解脫。
	其黃而隕：猶《裳裳者華》篇的「芸其黃矣」，芸也是黃色。黃：變黃。隕：隕落。
	自我徂爾，三歲食貧：徂，cú  ㄘㄨˊ：往；徂爾：嫁給你。食貧：過貧窮的生活。
	淇水湯湯，漸車帷裳：是說被棄逐後渡淇水而歸。湯湯：shāng ㄕㄤ，水勢浩大的樣子。漸：浸溼。帷裳：車旁的布幔。
	女也不爽，士貳其行：是說女方沒有過失而男方行爲不對。爽：差錯。貳：「貣（ㄊㄜˋ	tè）」的誤字。「貣」就是「忒（tè）」，和「爽」同義。
	罔：無；極：標準。
	二三其德：言行爲前後不一致。
	靡室勞矣：言所有的家庭勞作一身擔負無餘。室勞：家務勞動。靡：無。
	夙興夜寐，靡有朝矣：是說起早睡遲，朝朝如此，不能計算了。夙：早。興：起。
	言既遂矣：言生活既已過得順心。「言」字無義。既遂：就是《穀風》篇「既生既育」的意思。
	兄弟不知，咥其笑矣：是說兄弟還不曉得我的遭遇，見面時都譏笑我啊。咥，xī  ㄒㄧˉ：笑貌。
	靜言思之：好好地想一想。
	躬自悼矣：真爲自己感到悲傷。
	及爾偕老，老使我怨：當初曾相約和你白頭偕老，現在這句話徒然使我怨恨罷了。
	淇則有岸，隰則有泮：承上文，以水流必有畔岸喻凡事都有邊際。言外之意，如果和這樣的男人偕老，那就苦海無邊了。隰，xí  ㄒㄧˊ：低溼的地方；當作「溼」，水名，就是漯河，黃河的支流，流經衛國境內。泮，pàn  ㄆㄢˋ：通「畔」水邊，邊岸。
	總角之宴，言笑晏晏：總角，男女未成年時結髮成兩角，稱總角。宴，快樂。晏晏，和悅貌。
	信誓旦旦，不思其反：旦旦，誠懇的樣子。反，即「返」字。不思其反，言不想那樣的生活再回來。
	反是不思：是重複上句的意思，變換句法爲的是和下句叶韻。哉（古讀如茲zī）：語氣詞；末句等於說撇開算了罷！

憨厚農家小伙子，懷抱布匹來換絲。其實不是真換絲，找個機會談婚事。送郎送過淇水西，到了頓丘情依依。不是我願誤佳期，你無媒人失禮儀。情郎休要發脾氣，秋天到了來迎娶。

爬上那垛破土牆，遙向復關凝神望。復關遠在雲霧中，不見情郎淚千行。情郎即從復關來，又說又笑喜洋洋。你去卜卦求神仙，沒有凶兆心歡暢。趕著你的車子來，為我搬運嫁妝去。

桑樹葉子未落時，綴滿枝頭綠萋萋。噓噓那些斑鳩兒，別把桑葚吃嘴裡。哎呀年輕姑娘們，別對男人情依依。男人若是戀上你，要丟便丟太容易。女人若是戀男子，要想解脫難掙離。

桑樹葉子落下了，枯黃憔悴任飄搖。自從嫁到你家來，多年窮苦受煎熬。淇水茫茫趕我歸，水濺車帷濕又潮。我做妻子沒差錯，是你男人太刁蠻。反复無常沒準則，變心缺德耍花招。

婚後多年守婦道，繁重家務不辭勞。起早睡晚不嫌苦，忙裡忙外無休止。誰知心願滿足後，漸漸對我施暴力。兄弟不知我處境，個個見我皆恥笑。靜下心來細細想，獨自傷神淚暗拋。

當年發誓偕白頭，如今此願恨難平。淇水滔滔終有岸，沼澤雖寬有盡頭。回想少時多歡樂，談笑之間露溫柔。海誓山盟猶在耳，如今春夢已成空。莫再回想背盟事，既已終結便罷休！
