# 叔于田

---
<style>pre {white-space: pre-wrap !important; word-break: break-all;}</style>
	《詩說・鄭・尗于田》：尗叚多才而好勇，大夫憂之而作是詩，賦也。
另有一派認爲「叔」是特指鄭莊公之弟太叔段（共叔段）。《毛詩序》云：「《叔于田》，刺莊公也。叔處於京，繕甲治兵，以出於田，國人說而歸之。」
還有一派認爲「叔」非特指。今人陳子展《詩經直解》說：「《叔于田》，讚美獵人之歌。」程俊英《詩經譯註》也說「這是一首讚美獵人的歌」，以爲「叔」指青年獵手；袁梅《詩經譯註》則承朱熹《詩集傳》「或疑此亦民間男女相說之詞也」之說緒餘，說：「這支歌，表現了女子對愛人真純的愛慕。」以爲「叔」指男性情人。據《左傳・隱公元年》記載，太叔段勇而有才幹，並深得其母武姜的寵愛，被封於京地後，整頓武備，舉兵進攻鄭莊公，最終失敗外逃。若詩中之「叔」爲太叔段，則此詩當爲其擁護者所作，但並無明證。今人多不取《毛詩序》之說，而多認爲是讚美一位青年獵人的詩。

>叔于田、巷無居人。
豈無居人、不如叔也、洵美且仁。
三哥打獵在野地，里巷空曠不見人。
哪是真的不見人？沒人能與三哥比，確實俊美又謙仁。
叔：古代兄弟次序爲伯、仲、叔、季，年歲較小者統稱爲叔，此處指年輕的獵人。于（於）：去，往。田：同「畋」，打獵。
洵：真正的，的確。
叔于狩、巷無飲酒。
豈無飲酒、不如叔也、洵美且好。
三哥打獵在冬季，里巷再沒人喝酒。
哪是真沒人喝酒？沒人能與三哥比，那麼有爲又聰秀。
狩：冬獵爲「狩」，此處爲田獵的統稱。
叔適野、巷無服馬。
豈無服馬、不如叔也、洵美且武。
三哥打獵在郊外，里巷再沒人騎馬。
哪是真沒人騎馬？沒人能與三哥比，英俊勇武本領大。
野：郊外。服馬：騎馬之人。一說用馬駕車。
