# 宛丘

>
《詩說・陳・宛丘》：陳人譏其大夫之詩，賦也。近代學者多認爲是詩人對一位巫女舞蹈家的愛慕之情。
子之湯兮、宛丘之上兮。
洵有情兮、而無望兮。
你起舞熱情奔放，在宛丘山坡之上。
我誠然傾心戀慕，卻不敢存有奢望。
湯，dàng  ㄉㄤˋ：「蕩」之借字。遊蕩，放蕩。子：你，這裏指女巫。宛丘：四周高中間平坦的土山。
洵：確實，實在是。有情：盡情歡樂。望：德望。一說觀望；一說望祀；一說仰望。
坎其擊鼓、宛丘之下。
無冬無夏、值其鷺羽。
你擊鼓坎坎聲傳，宛丘下歡舞翩然。
無論是寒冬炎夏，持鷺羽舞姿美豔。
坎：擊鼓聲。
無：不管，不論。值：持。鷺羽：用白鷺羽毛做成的舞蹈道具。
坎其擊缶、宛丘之道。
無冬無夏、值其鷺翿。
你擊缶坎坎聲響，歡舞在宛丘道上。
無論是寒冬炎夏，持鷺羽舞姿漂亮。
缶：瓦盆，可敲擊發聲。
翿，dào  ㄉㄠˋ：傘形舞蹈道具。聚鳥羽於柄頭，下垂如蓋。
