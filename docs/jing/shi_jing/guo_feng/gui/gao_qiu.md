# 羔裘

---
<style>pre {white-space: pre-wrap !important; word-break: break-all;}</style>
	《羔求》：鄶君不能自強于政治，國人憂之而作，賦也。
	《毛詩序》：大夫以道去其君也。國小而迫，君不用道。好潔其衣服，逍遙遊燕，而不能自強於政治，故作是詩也。

---

>羔裘逍遙，狐裘以朝。豈不爾思，勞心忉忉。

>羔裘翱翔，狐裘在堂。豈不爾思，我心憂傷。

>羔裘如膏，日出有曜。豈不爾思，中心是悼。

	羔裘：羊羔皮襖。
	逍遙：悠閒地走來走去。
	朝：cháo ㄔㄠˊ：上朝。
	不爾思：即「不思爾」。
	忉忉：dāo ㄉㄠˉ，憂愁狀。
	翱翔：鳥兒迴旋飛，比喻人行動悠閒自得。
	在堂：站在朝堂上。
	膏：動詞，塗上油。
	曜：照耀。
	悼：悲傷。

穿着皮襖去逍遙，穿着狐袍去坐朝。怎不叫人費思慮，為你終日把心操。

穿着皮襖去遊逛，穿着狐袍去朝堂。怎不叫人費思慮，想起國家心憂傷。

皮襖色澤如脂膏，太陽一照金光耀。怎不叫人費思慮，心事沉沉徒悲傷。。
