# 采葛

---
<style>pre {white-space: pre-wrap !important; word-break: break-all;}</style>
	此詩舊說隨意性很大，如：
	《詩說・王・采葛》：賢者被讒，見黜于野，周人閔之而作，興也；
	《毛詩序》以爲是「懼讒」，所謂「一日不見於君，憂懼於讒矣」；
	朱熹《詩集傳》則斥爲「淫奔」之詩，說「采葛所以爲絺綌，蓋淫奔者託以行也。故因以指其人，而言思念之深，未久而似久也」；
	吳懋清《毛詩復古錄》則以爲采葛（蕭、艾）比喻平時蓄養人才，「臨時方獲其用，若求之太急……一日則如三月之久」；
	牟庭《詩切》又說是「刺人娶妻……而徒溺其色，一日不見，則思之如三月之久」；
	姚際恆、方玉潤、吳闓生卻一致認爲是懷友憶遠之詩，方氏申述雲：「夫良友情親如夫婦，一朝遠別，不勝相思，此正交情深厚處，故有三月、三秋、三歲之感也！」（《詩經原始》）近人則多主戀歌說。聞一多指出「採集皆女子事，此所懷者女，則懷之者男」（《風詩類鈔》）。

>彼采葛兮。一日不見、如三月兮。

>彼采蕭兮。一日不見、如三秋兮。

>彼采艾兮。一日不見、如三歲兮。

	葛：一種蔓生植物，塊根可食，莖可制纖維。
	蕭：植物名，蒿的一種，即青蒿，有香氣，古時用於祭祀。
	三秋：通常一秋爲一年，後又有專指秋三月的用法。這裏三秋長於三月，短於三年，義同三季，九個月。
	艾：植物名，菊科植物，可制艾絨灸病。

那個采葛好姑娘。一日不見，如隔仨月啊。

那個採蒿美姑娘。一日不見，如隔仨季啊。

那個採艾靚姑娘。一日不見，如隔三年啊。
