# 考槃

---
<style>pre {white-space: pre-wrap !important; word-break: break-all;}</style>考槃
《詩說・鄘・考槃》：美隱者之詩，賦也。
考槃在㵎、碩人之寬。
獨寐寤言、永矢弗諼。
遠離塵囂隱居到山澗之畔，偉岸的形象啊心懷寬廣。
即使獨身孤零零地自言自語，誓不違背當時隱居的高潔理想。
考槃（pán  ㄆㄢˊ）：盤桓之意，指避世隱居。一說盤爲木盤。【鄭箋】考，成也。槃，樂（lè  ㄌㄜˋ）也。槃樂，耽於玩樂。碩人：形象高大豐滿的人，不僅指形體而言，更主要指人道德高尚。寬：心寬。一說貌美。
寤：睡醒；寐：睡着。寤寐連用，即過日子。矢：同「誓」。諼，忘卻。
考槃在阿、碩人之薖。
獨寐寤歌、永矢弗過。
遠離世俗隱居到山崗之上，偉岸的形象啊心神疏朗。
即使獨身冷清清地唱歌，誓不忘記當時隱居的歡樂舒暢。
阿：山阿，山的曲隅。一說山坡。薖，kē  ㄎㄜˉ：貌美，引爲心胸寬大。
過：失也，失亦忘也。
考槃在陸、碩人之軸。
獨寐寤宿、永矢弗告。
遠離喧鬧隱居到黃土高丘，偉岸的形象啊心志豪放。
即使獨身靜悄悄地度日，誓不到處哀告不改變衷腸。
陸：高平曰陸。一說土丘。軸：徘徊往復，自由自在。一說美貌。
告：哀告，訴苦。
