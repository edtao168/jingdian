# 竹竿

---
<style>pre {white-space: pre-wrap !important; word-break: break-all;}</style>
《詩說・衛・竹竿》：宋桓夫人之媵和《泉水》而作，首章興也，二章、三章先比後賦也。《毛詩序》說：「《竹竿》，衛女思歸也。」寫的是一位遠嫁的衛國女兒，思念家鄉的情懷。
籊籊竹竿、以釣于淇。
豈不爾思、遠莫致之。
一枝釣竿細又長，釣魚釣到淇水上。
難道思念都拋卻？路遠怎能回故鄉！
籊籊，tì  ㄊㄧˋ：長而尖削貌。
爾思：想念你。爾，你。
泉源在左、淇水在右。
女子有行、遠兄弟父母。
左邊泉水細細流，右邊淇水長悠悠。
姑娘從此遠嫁去。父母兄弟天一頭。
泉源：一說水名。即百泉，在衛之西北，而東南流入淇水。
行：遠嫁。
淇水在右、泉源在左。
巧笑之瑳、佩玉之儺。
右邊淇水長悠悠，左邊泉水細細流。
粉臉嬌笑多可愛，佩玉叮噹慢慢走。
瑳，cuō  ㄘㄨㄛˉ：玉色潔白，這裏指露齒巧笑狀。
儺，nuó  ㄋㄨㄛˊ：通「娜」，婀娜。一說行動有節奏的樣子。
淇水滺滺、檜楫松舟。
駕言出遊、以寫我憂。
淇水水流不回頭，檜木槳搖松木舟。
再次駕船水上游，但願能解心中愁。
滺，yōu  ㄧㄡˉ：河水盪漾之狀。楫：船槳。檜、松：木名。檜，柏葉松身。
言：語助詞，相當「而」字。寫：通「瀉」，排解。
