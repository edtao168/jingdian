# 相鼠

---
<style>pre {white-space: pre-wrap !important; word-break: break-all;}</style>相鼠
《詩說・鄘・相鼠》：刺三尗之詩，興也。這首詩古有二說：《毛詩序》以爲是刺在位者無禮儀，班固《白虎通義・諫諍篇》則認爲是「妻諫夫之詩」，此本《魯詩》說。
相鼠有皮、人而無儀。
人而無儀、不死何為。
你看老鼠都要皮，人卻不講儀。
人若沒有儀，不去死還想幹嘛？
相：視也。儀：禮儀也。
相鼠有齒、人而無止。
人而無止、不死何俟。
你看老鼠都有齒，人卻不知恥。
人若不知恥，不去死還想怎樣？
止：假借爲「恥」，鄭箋釋爲「容止」，也可通。俟：等。
相鼠有體、人而無禮。
人而無禮、胡不遄死。
你看老鼠都有體，人卻沒有禮。
人若沒有禮，爲何還不快去死？
體：肢體。胡：何。遄，chuán  ㄔㄨㄢˊ：快，速速。
