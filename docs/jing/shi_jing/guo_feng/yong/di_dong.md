# 蝃蝀

---
<style>pre {white-space: pre-wrap !important; word-break: break-all;}</style>蝃蝀
《詩說・衛・蝃蝀》：衛靈公為南子召宋朝，國人譏之，二章皆先比而後賦也，末章賦也。
蝃蝀在東、莫之敢指。
女子有行、遠父母兄弟。
一條彩虹出東方，沒人膽敢將它指。一個女子出嫁了，遠離父母和兄弟。
蝃蝀：彩虹，愛情與婚姻的象徵。蝃，dì  ㄉㄧˋ，同「螮」。蝀，dōng  ㄉㄨㄥˉ。在東：彩虹出在東方。有行：指出嫁。
朝隮于西、崇朝其雨。
女子有行、遠兄弟父母。
朝虹出現在西方，整早都是濛濛雨。一個女子出嫁了，遠離兄弟和父母。
隮，jī  ㄐㄧˉ：一說升雲，一說虹。崇朝：終朝，整個早晨，指從日出到吃早餐的時候。
乃如之人也、懷昏姻也。
大無信也、不知命也。
這樣一個惡女子啊，破壞婚姻好禮儀啊！太沒貞信太無理啊！父母之命不知依啊！
乃如之人：象這樣的人。懷：古與「壞」通用，敗壞，破壞。昏姻：婚姻。大：太。信：貞信，貞節。命：父母之命。
