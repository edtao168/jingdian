# 鶉之奔奔

---
<style>pre {white-space: pre-wrap !important; word-break: break-all;}</style>
《詩說・衛・鶉之奔奔》：刺宣姜與公子頑之詩，興也。
鶉之奔奔、鵲之彊彊。
人之無良、我以為兄。
鵪鶉雙雙共棲止，喜鵲對對齊飛翔。那人腐化又無恥，我竟尊他作兄長。
鶉：鳥名，即鵪鶉。奔奔：跳躍奔走。鵲：喜鵲。彊彊（jiāng  ㄐㄧㄤˉ）：翩翩飛翔。奔奔、彊彊，都是形容鶉鵲居有常匹，飛則相隨的樣子。
無良：不善。我：「何」之借字，古音我、何相通。一說爲人稱代詞。
鵲之彊彊、鶉之奔奔。
人之無良、我以為君。
喜鵲雙雙齊歌唱，鵪鶉對對共跳奔。那人腐化又無恥，我竟尊他爲國君。
君：指衛宣公。
