# 序

## 易
《易》也叫《易經》、《變經》或《古經》，「經」字特指原文內容。《易》原有三種版本：《連山》、《歸藏》和《周易》，《連山》和《歸藏》已經失傳，唯《周易》有幸傳世，因此《易經》通常便泛指《周易》。
《周易》，周，東漢鄭玄《易論》認為「周」是「周普」的意思，即無所不備，周而復始。唐孔穎達《周易正義》認為「周」是指中國陝西省岐山縣（古稱西岐，西周發祥地）地名，是周朝的代稱。易者，變易，簡易，不易也。《周易》被儒家視為「六經之首」，又被道家稱為「大道之源」。
《易經》六十四卦，分成上下兩個部分，上經所重的是天道，是自然；下經所重的是人道，是感情。

## 易傳
後人對《周易》作註解的版本眾多，其中最早也是最著名的作品就是《易傳》。《易傳》，漢代學者稱之為《十翼》，《易傳》的上半部為「經」的部分，是引用《周易》的原文；《易傳》的下半部為「傳」的部分，是由孔子及弟子們聯合撰寫，對周易進行個人見解注釋。「傳」的內容包含〈彖（tuàn  ㄊㄨㄢˋ）辭〉上下（彖傳）、〈象辭〉上下（象傳）、〈繫辭〉上下、〈文言〉、〈序卦〉、〈說卦〉、〈雜卦〉共七種十篇，「翼」即輔翼經文之意。《彖傳》和《象傳》二者的共同點是：通過闡釋卦象、爻象所蘊涵的道理，告知人們如何正確決定自己的行動。
* 〈彖傳〉上下兩篇，《易經》六十四卦，每卦都有「彖曰」，也叫做「彖辭」。「彖」是「斷」的意思，「彖辭」則是用來論斷一卦的卦象、卦辭和六爻的排列。
* 〈象傳〉上下兩篇，六十四卦每卦「彖曰」後面，緊接著是「象曰」，稱為「大象」，總論這一卦的象。每一卦有六爻，爻辭後面的「象曰」，叫做「小象」，分論這六爻的象。象的功能，在模擬萬物型態和事理。
* 〈繫辭傳〉上下兩篇，「繫」的意思是聯絡，把易道的義理聯繫起來，相當於《易經》的總論或通論。上篇以形而上的道體為主，下篇以形而下的器用為主，合起來可以稱為「易大傳」。
    • 〈說卦傳〉一篇，說明八卦所代表的意義，以及八卦相重的由來。
    • 〈序卦傳〉一篇，說明六十四卦的次序，和排列的理由。
    • 〈雜卦傳〉一篇，以另一種形式來解釋六十四卦的卦名。
    • 〈文言傳〉一篇，就乾卦與坤卦作充分詳細解說。可能是後世易學家的見解所輯錄而成。
## 八卦
《易傳．繫辭上》：易有太極，是生兩儀，兩儀生四象，四象生八卦，八卦定吉凶，吉凶生大業。
太極：《說文解字》中說：「惟初太極，道立於一，造分天地，化成萬物」，太極就是天地、乾坤、剛柔、陰陽等一切相對事物的一個混合體；可以將太極視為天地未開、混沌未分陰陽之前的狀態。
兩儀：就是對立統一、相輔相成的矛盾事物；最常見的說法是指陰陽，八卦中「--」代表陰爻，「—」代表陽爻。《易經．繫辭上》：「爻者，言乎變者也。」
四象：兩儀在運動對立的過程中，會出現陰與陽的消長，這引起了四種新的狀態：「太陽9（老陽）、少陽7（上陽下陰）、少陰8（上陰下陽）、太陰6（老陰）」，這就是四象；四象亦指東青龍、西白虎、南朱雀、北玄武，此外人們又將「春夏秋冬」視為四象，又稱為四時。
八卦：四象進一步演化而化生萬物；將世間萬物歸類，古人將其分別由八個卦表示：「乾、兌、離、震、巽、坎、艮、坤」。
六十四卦
周文王將八卦兩兩搭配，得到六十四卦，用來象徵各種自然現象和人事現象，《易經》基本上就是用來解釋六十四卦的。

六爻：《繫辭下》：「六爻相雜，唯其時物也。其初難知，其上易知，本末也。初辭擬之，卒成之終。若夫雜物撰德，辨是與非，則非其中爻不備。噫！亦要存亡吉凶，則居可知矣。知者觀其彖辭，則思過半矣。二與四同功而異位，其善不同，二多譽，四多懼，近也。柔之為道，不利遠者，其要無咎，其用柔中也。三與五同功而異位，三多凶，五多功，貴賤之等也。其柔危，其剛勝邪。」
吉凶：曾仕強說：「順從易理，有所得，吉；違反易理，有所失，凶。如何趨吉避凶，要做到後悔在先，不要後悔在後。」
易經體例
    • 卦象（卦畫）：六爻畫成的樣子。
    • 卦辭（繫辭）：綜合說明此卦的現象。
    • 彖辭：判斷整個卦名，解釋卦辭，以及說明全卦的要義。
    • 象辭：卦整體的象叫「大象」，爻裡面的象叫「小象」。
    • 爻辭：解釋每個爻的用意。爲了讓我們對爻辭有更進一步的了解，所以每一爻的爻辭後面，都配上一個小象。根據這一爻的象，看它的上下關係、對應關係。
    • 最後要對每一爻作判斷，
        ◦ 是否當位？陽位一三五，陰位二四六，若陽位一是陽爻，就是當位（如《既濟》），否則不當位（如《未濟》）。
        ◦ 是否相應？相應就是跟遠方的感應，例如下卦的初爻和上卦的初爻正好是一陰一陽，就叫相應（如《泰》），否則就叫不相應（如《兌》）。以此類推，二五爻、三六爻也是如此。
        ◦ 相鄰的爻有四種關係，一是上下爻一樣，叫「比」，它們有連帶作用，有增強、擴大的能量。二是上陰下陽，叫「凌乘」，表示陰凌乘陽，多半不好。三四都是上陽下陰，按陽的角度來看，叫「陽據陰」，陽若是以爲能吃定陰，那就不好，陽若是感謝陰，叫「陰承陽」，表示陰的承載、配合、支援。
本卦：排在前面的第一個卦，叫本卦，又叫主卦、原卦。它體現的是事物初始、開始階段的資訊，或目前的情況。 
綜卦：將一個卦倒過來看，後一卦既是前一卦的「綜卦」，後一卦的初爻就是前一卦的上爻。在六十四卦中，有八個卦沒有綜卦：乾、坤、離、坎、小過、大過、中孚、頤。因其各自的「綜卦」仍是本卦。
錯卦（相錯）：將一個卦的陽爻變成陰爻、陰爻變成陽爻，即六爻全變，兩個卦的卦象剛好相反，後一個卦既是前一個卦的「錯卦」。「上下經卦名次序歌」中，沒有綜卦的八個卦既按錯卦成對排列。比如，乾坤，坎離，中孚和小過。
交互卦：將一個「主卦」的二、三、四爻組成另一個卦的下卦，這個「下卦」稱為主卦的「互卦」，同時將主卦的三、四、五爻組成另一個卦的上卦，這個「上卦」稱為主卦的「交卦」，新組合的卦，稱為主卦的「交互卦」。比如，地天泰，二、三、四爻分別為九二、九三、六四——兌；三、四、五爻分別為九三、六四、六五——震。即，泰的互卦（下卦）是兌，其交卦（上卦）是震，故泰的交互卦是雷澤歸妹。乾卦的交互卦仍是乾卦，坤卦的交互卦仍是坤卦。每一卦會有五個互卦，加上綜卦、錯卦，與本卦有關的卦有十五個。
異卦：指上卦與下卦不一致的卦，卦書中寫做「異卦相疊」，即異卦。異卦有五十六卦。
