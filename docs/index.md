# 散修讀經典

歡迎來到【散修讀經典】，這是一個沒有宗門，資源貧瘠、修為普通的人閱讀經典後的理解。我不是大能，理解不一定正確，看時不要太挑剔，看完可以指正，但別跟我較真。本站採用傳統「經、史、子、集」四部法整理歷代重要典籍。

## 🏛️ 部類簡介

* **經部**：儒家核心經典（《論語》、《詩經》等）。
* **史部**：歷代史書典籍。
* **子部**：諸子百家思想（《老子》等）。
* **集部**：歷代詩詞文學總集（《楚辭》等）。
